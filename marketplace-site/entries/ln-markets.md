# LN Markets

> Leveraged Bitcoin futures positions and BTC↔synthetic-USD swaps, funded and settled over Lightning

A Bitcoin derivatives venue on Lightning — perpetual futures and a BTC/synthetic-USD swap, funded and withdrawn over Lightning or on-chain.

- Category: swap
- Payment methods: lightning, onchain
- Custody: custodial-while-trading
- Automatability: api-account — API after account setup — no identity check, but a human creates the account first
- Auth: api-key
- API base: https://api.lnmarkets.com/v3
- Quickstart: Register (email + verification), create a scoped API key on the profile, then sign requests to api.lnmarkets.com/v3; test against api.signet.lnmarkets.com/v3 first. LNURL-auth is available as an additional sign-in method, not a substitute for the account.
- Site: https://lnmarkets.com
- Docs/API: https://docs.lnmarkets.com/en/api
- Full card (verified detail, gotchas): https://bitcoineconomy.ai/exchanges/ln-markets
- Provenance: curated (last verified 2026-08-03)
